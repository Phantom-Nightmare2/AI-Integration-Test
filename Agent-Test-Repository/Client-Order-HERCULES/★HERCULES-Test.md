試験概要

本フォルダーは、★HERCULES専用のAIエージェント能力試験です。

ノーマルエージェントより高度な課題を設定し、実際のクライアント案件を想定した能力評価を実施します。

評価対象

プログラミング能力

エラー・バグの原因調査能力

自律的な問題解決能力

コードの修正・実装能力

動作確認・テスト能力

クライアント指示への対応能力

基本ルール

クライアントオーダーに従って作業すること。

不明な内容は自律的に調査すること。

問題ごとに原因・修正内容・検証結果を報告すること。

GitHubへのコミット・プッシュは明示的な許可がある場合のみ行うこと。

試験問題

テスト問題とクライアントオーダーは、このフォルダー内に別ファイルとして配置します。
